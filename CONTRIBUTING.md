# Contributing to atlas-agent

## Before contributing

- Read `AGENTS.md`, `docs/PROJECT_WORKFLOW.md` and `docs/TESTING.md`.
- Search existing issues before opening a new one.
- Do not include secrets, personal data or generated production data.

## Contribution flow

1. Open or reference an issue describing the problem or proposal.
2. Create a short-lived branch from `main`: `feature/<topic>`, `fix/<topic>`, `docs/<topic>` or similar.
3. Make focused, atomic commits using Conventional Commits.
4. Run the documented validation commands.
5. Open a pull request that explains the change and references the issue.
6. Rebase on the target branch if requested; after merge, delete the branch.

## Pull request expectations

- Keep the scope focused.
- Include tests for changed critical behavior.
- Update user-facing documentation, configuration examples and roadmap entries where applicable.
- Explain any intentional compatibility, migration or security impact.

## Code of conduct

Be respectful. Harassment, discrimination, deliberate malice and disclosure of private information are not accepted.
